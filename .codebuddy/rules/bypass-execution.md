# 旁路执行（项目规则）

## 强制规则

**本项目唯一终端执行方式为旁路执行（spawn bash 子进程）。**

- **禁止**使用 VSCode 集成终端、系统 Terminal.app、iTerm2 等任何终端模拟器
- **禁止**要求用户在终端中手动输入命令
- **所有命令**必须通过 IDE 旁路执行通道发出，AI 自动构造并执行
- 唯一例外：用户**明确**说"你在终端里手动执行"时才能用其他终端

## 三条核心约束

1. **无状态**：每条命令是独立 shell，`cd`/`export`/`source` 不延续，所有依赖前一条状态的命令用 `&&` 连成一条
2. **禁止交互**：交互式命令（需要用户输入）会永久卡死，必须用非交互式替代方案
3. **管道复核**：`git push` 等关键操作后必须用独立命令复核退出码（管道会吞错误）
