# EV-UI·Android（`ev-ui-android`）· 项目规则指针

**规范 ID**：`ev-ui-android`（EV-UI 家族 · **仅安卓同步器**；其他平台册见正文「命名法与防冲突约定」）。
**正文唯一真源**：`docs/EV-UI-Android-v1.md`。
**本文件只管安卓同步器**；手环快应用 / 网页 / iOS 的 UI 规范请用各自的 `ev-ui-<平台>` 册，不要往本文件加。
按总纲 §3.5a「正文只写一份」，此处**不重复正文**，只留指针与最低限度的硬约束。
适用：`apk/src/com/application/watch/classschedule/` 下所有页面与组件，含以后新增页面。

## 改任一页面前必读正文，并遵守

1. 颜色 / 字号 / 行高 / 间距 / 圆角 / 热区**全部从 `Ui.java` token 取**；新代码禁止写死颜色（`0xFF...` / `Color.parseColor`）、字号、圆角、任意 `setElevation`。
2. 三个强制工厂（不只是审美，是已修 P0 的防回归线）：页面入口 `Ui.screen()`、输入框唯一入口 `Ui.editText()`、onResume 重建只走 `Ui.needRecreate()`。
3. 中文标题用 `Ui.textMedium*`，不用 `bold`；图标走 Lucide 线性 vector，禁止 emoji / Unicode 符号（总纲 §3.14、本仓 `.trae/rules` Icon Policy）。
4. 新增 token 必须**先改 `Ui.java` + 更新规范 §3 表格**，才允许页面使用。
5. 提交前跑 `python3 tools/check-ui-spec.py`；存量 200 处（`--all` 口径，v1.3 起含 elevation）按「改到才收敛」豁免，脚本只卡新增行。
6. **禁止**新开一份「XX 页全新设计方案」而不回流规范正文 —— 那是风格漂移的源头；新方案只能作为规范附录或修订，并更新 §10 变更日志。
7. 不引入第三方 UI 库（Compose / MDC-Android / XUI / QMUI_Android），理由见规范 §1。
8. **面向中小学生（9–18 岁）是最高优先级**：可见文案按「小学四年级能读懂」写，禁止 `设备ID / 握手 / 回包 / 穿戴服务 / APK / 签名 / 错误码 / 后台应用` 等工程黑话；一句一个动作、≤15 字、错误提示给「发生了什么 + 现在能做什么」。词表与替换示例见规范「设计宪法」B，脚本会拦新增行。
9. **简单大方 / 好用是 P0，动画只是 P2 点缀**：每屏至多 1 处、≤200ms、不阻塞操作、不自动循环、不替代状态文字、系统减少动态效果时降级为静态；不为加动效改存量页面。六条红线见规范「设计宪法」C。

10. **改错误文案必须同步改判断词**：错误详情既是显示文案，也是 `d.contains(...)` 判断恢复建议的依据；人话化后要让匹配函数同时认旧说法与新说法（见 `DebugActivity` 四个 `isXxx` 方法），否则按钮会指错方向。规范「设计宪法」B 第 4 条。
11. **改视觉必须真机前后截图比对（Tom 2026-11-05 明令）**：`build.sh` → `adb install -r -g` → 同机同页截 before/after → 放大并排比对；设计图只是意图，真机渲染才是事实，两者不一致时修实现。截图不可用时明确标注「未验证」，禁止拿设计图冒充实拍。规范 §7「真机截图比对铁律」。
12. **课程块色条只能用 `Ui.CourseBlockDrawable`**（矩形 ∩ 圆角轮廓）；禁止 `LayerDrawable` 叠两张各自圆角的 `GradientDrawable` + `setLayerInset`，那会产生上下两端斜切刺头（v1.3 已修，见附录 D）。

## 验收

真机**改前/改后各一屏并并排比对**（≤8dp 细节放大看）、浅色 / 深色各一屏、中文输入法弹收不黑屏、主题切换不连环重建、44dp 热区（新页面 48dp）、正文对比度 ≥4.5:1；再加**朗读测试**与**动画红线逐条核对**；截图归档 `apk/shots/`、对照页归档为规范附录。
详见规范 §7。
