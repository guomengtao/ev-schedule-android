## 鸿蒙适配方案（用户补充：别的同步器能用 → 不是鸿蒙无解，是通道选错）
- 新增文档 `纯血鸿蒙适配方案-直连蓝牙与备选.md`（commit 5e107f3，bump 0.5.6）。
- 关键认知修正：别人同步器能用 = 卓易通沙箱大概率开放蓝牙；我们卡死是因为走「小米运动健康 AIDL」（沙箱里没有），不是鸿蒙连不上手环。
- 主推方案①：自研 BLE 直连，绕开运动健康，EV 侧接口不改（只换传输层）；可复用 AstroBox 的 `XIAOMI-VELA-V5-PROTOBUF` transport + 参考 Gadgetbridge 的 Mi Band 鉴权。三大难点：鉴权/加密、连接竞争（与官方 App 抢连接）、卓易通蓝牙开放度未知。
- 方案② 鸿蒙原生 HAP（长期、依赖小米开放接口）；方案③ 检测鸿蒙+明确提示（本周可做，止血）；方案④ 桌面插件兜底（已有）。
- 落地第一步：写最小 BLE 探针 APK 丢卓易通验证能否扫/连手环，结果决定路线。

## 手环9陶瓷版用户卡在第一步的归因分析
- 新增文档 `第一步连接失败分析-手环9陶瓷版.md`（commit cb98981 → adfa226，bump 0.5.5）。
- ★ **真因已定位**：该用户手机是纯血鸿蒙（HarmonyOS NEXT），APK 经「卓易通」安卓沙箱运行。卓易通沙箱内的进程无法绑定沙箱外鸿蒙原生「小米运动健康」的 AIDL 穿戴服务 → `getServiceApiLevel()` 必然失败 → 卡第一步。与手环 9 陶瓷版无关，纯 Android/HyperOS 用户不受影响。
- 结论：环境不支持，无修复方案；安卓版运动健康装进卓易通也没用（BLE 连接由鸿蒙原生 App 维护）。如需支持鸿蒙需出原生 HAP，且依赖小米在鸿蒙侧开放第三方接口，短期不现实。

## 新增分析文档：首页滚动/留言模式/导入多选/常驻底栏/导出清单
- 文档 `docs/ui-message-import-export-improvements.md`（本次 commit，bump 0.5.12）。
- **首页滚动失败真因（已定位）**：`Ui.wrapWithBottomBar` 里 `scroll.addView(contentRoot)` 未传 LayoutParams → ScrollView(FrameLayout) 默认给 **MATCH_PARENT 高度** → 内容被裁、滚不动（经典坑）。修法：显式 `FrameLayout.LayoutParams(MATCH_PARENT, WRAP_CONTENT)` + 内容区加底栏高度的底部 padding（底栏悬浮会盖住内容尾部）。
- **附带 bug**：`wrapWithBottomBar` 强制删最后一个子 View；`HomeActivity`/`ChatActivity` 从未 addView(bottomBar)，导致被删的是"包名版本号/说明文本"。`SettingsActivity` 那行 `addView(bottomBar)` 是死代码。
- **常驻底栏**：`TransferActivity`/`DebugActivity` 完全没有底栏 → 用户"看不到三个按钮"的直接原因。方案：统一 BaseActivity，底栏唯一在一处生成。
- **留言模式**：下行 `chat`→`ev_chat_inbox`+长震 已就绪，手机端只需本地队列+连接后补发；上行"连接后获取"建议手机主动 `pull_messages`（EV 侧新增，跨仓需授权）。
- **后台监控结论**：能（前台服务+1~5min 周期轮询，Binder 回调不受 Doze 限）但**进程被杀后收不到**（无推送通道）→ 文案别用"实时"；保底必须做 onResume 拉取。targetSdk34 需 foregroundServiceType=dataSync + POST_NOTIFICATIONS + VIBRATE。
- **导出清单失败（重点）**：APK `loadSchedules` 解析与主仓 `syncHandleListSchedules` 回包**协议一致**；最可能是**手环 EV 版本过旧（<1.6.139，无 list_schedules）** + APK 失败静默无提示。修法：可见清单列表 + 明确报错 + `export` 兜底。
- **导入页**：现状只有选文件；需加 粘贴框 / 随机示例 JSON / 复制按钮 / 多选课预览（对标 `app-auth/tools/ev-schedule-sync/preview.html`）。EV import 字段要求：`day`+`name`+`time`（或 startTime/endTime、startPeriod/endPeriod），可选 teacher/location/notes；import 是**覆盖**当前表（无合并）。
