- 定位：编辑课程 = `src/pages/detail/detail.ux`（4 步向导），非 `lab-edit-course.ux`（未进 manifest 的 Demo）。全页文字都是 `theme.text/textSecondary/textMuted` token，CSS 无硬编码颜色。

## 更正：真正的根因是「布局挤压」，已修复
- 用户纠正：不是「看不见字/颜色问题」，而是**编辑课程第一步（选择课程）课程名被左右箭头挤成省略号（2 个白点）**。课程名框太小 + 小屏没有 min-width 保护，被两侧箭头挤扁。
- 根因：`detail.ux` 胶囊屏块 `.course-card { flex:1; min-width:0; width:auto }` + `.swiper-wrapper { justify-content: space-between }`。Vela 窄屏下 `flex:1` 的 flex-grow 退化、卡片塌缩到接近 0，课名被 `text-overflow: ellipsis` 截成「…」。
- 修复（`detail.ux` 胶囊屏块）：`.course-card` 改固定 `width:100px; min-width:100px; flex-shrink:0`；箭头 36→26px；`justify-content` 改 center；页面 padding 16→12px；课名字号 22→20px（4 字课名放得下，5 字 ellipsis 兜底）。
- 文档已重写为布局挤压版。commit+push（class-schedule main，commit `4286c86`），只 add detail.ux + 文档。
- ★ 教训：手环 9（pill-shaped 胶囊屏 192px）上 Vela 的 `flex:1`/`width:auto` 测量退化不可靠，窄屏横向布局应**固定宽度 + flex-shrink:0**，勿依赖 flex:1 撑满。同文件 circle 块早有注释记录同款坑。
