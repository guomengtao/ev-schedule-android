3设计意图速览

  • 一个状态源：删 ConnectionBar、删状态卡「连接」行 → 连接状态只在设备卡出现一次。
  • 展示归展示：设备状态从六行清单 → 2 列指标网格，电量做视觉锚点，一眼扫完。
  • 主操作上桌：「腕聊」从第四条设置项 → 独立主操作卡（本页真正的高频动作）。
  • 危险动作不露脸：11sp 裸「▼」（清除记忆重连）→ ⋯ 菜单，带副文案说明后果。
  • 排障不占位：「连接调试」常驻页底 → ⋯ 菜单 + 未连接引导卡里的文字链。
  • 空态会说话：未连接不再满屏「—」，收敛成一张引导卡（线稿 + 怎么做 + 主按钮）。
  • 表单消失：昵称卡三段式表单 → 设置行 + 底部弹层。
