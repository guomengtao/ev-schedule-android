# 首页美化方案（周视图课表区域）

> 2026-09-28 · 针对「课程表区域太乱」的分析与改造记录  
> 现状截图基线：`~/Desktop/ev-ui-home.png`（改造前）

---

## 一、问题诊断（改造前的「乱」从哪来）

| # | 问题 | 根因 | 严重度 |
|---|---|---|---|
| 1 | **空格子显眼**：无课的时段铺满浅灰圆角块，整张表像「格子布」，课程块反而被淹没 | 空槽画了 `CARD` 色背景（`weekGridWithTime` 的 empty 分支） | ★★★ |
| 2 | **今天高亮越界**：翻到上周/下周时，表头和列背景依然高亮「周一~周日里今天对应的列」 | `d == today` 没有周偏移判断 | ★★ |
| 3 | 课程块圆角太小（5dp），与页面其他卡片（12~16dp）风格脱节 | 硬编码 | ★ |
| 4 | 周切换箭头是纯 TODO 空壳，点了没反应 | 并行开发遗留 | ★★★ |
| 5 | 日期条（dateStrip）与周标签「9.28-10.04」各自为政：切换周后日期条不动、标签不变 | 无 weekOffset 状态 | ★★ |

## 二、本轮已实施（v0.5.44+）

1. **空槽透明化**：无课时段不再画灰块，只留课程块 —— 「乱」的最大来源直接消除，界面立刻只剩有效信息。
2. **周切换落地**：`‹ ›` 每次切一周（`weekOffset ±1`），周标签与日期条同步跟随；**点周标签回到本周**。
3. **今天高亮限定本周**：翻到其它周时不再错误高亮「今天的星期几列」，只有本周才显示今天列淡色蒙层 + 表头主色。
4. **课程块圆角 5 → 7dp**，与整体卡片语言统一。
5. 返回按钮由 arrow-left（←）改为 **chevron-left（‹）**，更轻量（全部子页生效）。

## 三、后续美化候选（按收益排序，未实施）

1. **课程块两行化**：课程名 + 教室/教师第二行（需 `CourseCache.Course` 暴露 room 字段；9sp 白字两行在 40dp 高度内放得下）。
2. **「当前正在进行」的课程块呼吸描边**：按当前时间高亮正在上的课，一眼定位。
3. **连续大节合并**：同一门课连续 2 节合并成一块（数据里 start/dur 可推导），减少碎块。
4. **今天列的日期角标**：表头「三」下加当日日期数字，与日期条呼应。
5. **左右滑动切周**（GestureDetector），箭头保留为辅助。
6. 课程块配色跟随主题：`COURSE_COLORS` 目前是固定 7 色，深色主题下可整体降饱和。

## 四、设计约定（后续改动必须遵守）

- 图标只用 **https://lucide.dev/icons/** 的 24×24 / 描边 2 矢量（`apk/res/drawable/ic_*.xml`），禁止 emoji 当图标。
- 颜色一律取 `Ui.*` token，禁止页面写死色值。
- 底栏选中态 = 仅图标/文字变色，**永不加背景**。
- 子页顶栏 = `Ui.header()`（chevron-left + 标题）；三个 tab 主页不加返回键。
