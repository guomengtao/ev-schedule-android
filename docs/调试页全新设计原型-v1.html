2改了什么（一眼对照）

  • 说明文字 → 状态总览条：静态的一句指引换成随时更新的「几点通过 / 停在哪一步」。
  • 8 个平铺按钮 → 3 个分组：链路自检 / 单项探测 / 报文·日志，各有分组标题。
  • Ui.row 灰砖 → 白卡 + 状态竖条：卡片边界不再消失，状态一眼可辨。
  • 常驻「打开小米运动健康」→ 失败时就地建议：只在步骤 2 失败时出现，位置贴着出问题的那一步。
  • 重置 / 清屏降为 ghost：破坏性动作不与常用动作抢主按钮位。
  • 裸 EditText → 等宽输入区：CARD2 底 + 描边 + padding，11.5sp 合规。
  • 3 处越界字号归位：13.5 → 13（SP_BODY）、12 → 11.5（SP_CAPTION）、11 → 11.5（SP_CAPTION）。
