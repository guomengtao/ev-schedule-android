  • 字号层级：页标题 20sp / 区块标题 16sp(medium) / 正文 14sp / 说明 12sp；行高 1.5 倍，系统字体放大 200% 不截断。
  • 间距栅格：4dp 基准，卡片内 12dp、卡片间 8dp、分组间 16dp；圆角 3 档（卡片 12 / 控件 8 / 色条 4）。
  • 热区：主按钮 48dp、场景切换 chip 44dp；状态不靠颜色单独表达 —— 结果条同时有左侧色条 + 文字。
  • 动效：本页只有 chip 切换的 150ms 过渡（≤200ms 红线），不自动循环、不阻塞操作；系统开启「减少动态效果」时降级为静态。
  • 状态四态：默认「输入 4 位兑换码」→ 加载「正在找手环…」→ 错误「手环没回答，再点一次」→ 成功「激活成功 / 回首页」，每态一句人话、不出现技术词。

对比度数值按 WCAG 2.1 相对亮度公式实算；两处不达标的建议色只写在设计图里，本次未改 App 颜色（本轮是文案试点）。

验收与边界

两页学生可见硬禁词 0 处（FastActivate / ZeroActivate） check-ui-spec.py 新增行 0 硬违规 11 处软提醒：「兑换码 / 激活码」为功能名，按 B 例外保留 原始 json / reason / 设备号不再显示，转入日志 朗读测试：小学四年级能说出「手环没答话，再点一次」 动画 0 处新增（P2 不主动加）
  • 本次范围：FastActivateActivity.java 22 条 + ZeroActivateActivity.java 14 条替换，只改面向学生的字符串与两处「原文转日志」；内部变量名、日志、成功卡与购买流程未动。
  • 第 4 条硬规则已复核：这两页没有任何中文错误文案的 contains(...) 判断，人话化不会改坏恢复动作（与附录 B 的坑不同）。
  • 边界：ZeroActivate 的「调试探针」态仍显示 MAC / 手环编号给排障用，属开发者态；其它页面（同步协调器、传输页、主题选择页）的存量黑话按 §6「改到才收敛」留给后续。
  • 真机：Android 真机 / AVD 不在线，效果以本设计图呈现；未构建发布、未动线上升级清单。
