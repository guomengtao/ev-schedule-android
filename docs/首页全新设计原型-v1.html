Ev 课程表 · 手机 App 首页「全新设计」原型 v1

对象：EVSyncProbe（Android）HomeActivity · 画布 360×640 dp（真机 BLN-AL20 1080×1920@480dpi）· 下列原型 1 dp = 1 px，标注数值可直接换算成代码。

配色沿用 Ui.java 晴空蓝 / 夜幕蓝双主题 间距 4dp 栅格 圆角 4 / 12 / 14 三档 字号 7 档阶梯 热区 ≥44dp 对比度 WCAG AA

01现状诊断：不是"不好看"，是"没层级"

逐行核对 HomeActivity.buildUi() 后的结论——现有首页把 5 类信息（身份 / 时间导航 / 课表 / 设备动作 / 连接状态）平铺成 8 个等高区块，用户视线没有落点。

现状（自上而下 8 块，权重相等）

1
顶栏：问候 + 「Ev课程表」居中大标题 + 10dp 状态点 + ⊕
App 名对用户零信息量；状态点 10dp 太隐蔽，多数人不知道能点
2
正文首行又一个大标题「本周课表」 + 周切换 ◀ ▶
与顶栏标题语义重复，全页出现两个"标题"
3
日期条（64dp 高卡片 × 7） — 星期日历
4
网格表头（36dp spacer + 一二三四五六日） — 星期日历，与 ③ 重复一遍
5
课表名行：🔁课表名 + [单] + ✏️
6
周课表网格
7
快捷 2×2（呼叫手环 / 上课了 / 留言 / 下课了） — 4 个入口占 1/4 屏高
8
迷你状态条（瞬时） / 错误卡（按需）

三个结构性问题

A
双标题、双日历
「Ev课程表」+「本周课表」两个标题；日期条 + 网格表头两份"一二三四五六日"。约 100dp 竖向空间用于重复信息。
B
最高频的问题没有答案
用户打开 App 第一句问的是「我下一节课是什么」。现有页面只能靠"在 7×N 小格子里找今天那一列"回答，今天列仅有一层淡蓝底。
C
设备动作与课表抢视觉
快捷 2×2 与课表等宽等高；且"留言"是页面跳转、"呼叫/上课/下课"是设备命令，三者不同域却同权重。
底栏还有一个隐藏的语义冲突
首页（周课表） 与 课程表 tab 在用户认知里是同一件事。建议把 tab 文案改为 「课表库」（它实为多套课表的管理列表 ScheduleListActivity），冲突即消。

02设计主张：一屏「现在 → 本周」

首页只回答两个问题，按重要性排序：① 我现在该干嘛（接下来） ② 这周整体什么样（课表）。其余全部降级为"随手可及"。

决策做什么为什么
D1 去 App 名顶栏删掉「Ev课程表」，改为 问候 + 状态胶囊 + 设置，高度 52→44dp用户不会忘记自己在用哪个 App；省下的注意力全给内容
D2 新增「接下来」课表上方加一张焦点卡：下一节课名 / 时间 / 地点 / 距开课倒计时 / 今日进度把最高频问题提到首屏第一个视觉落点；这也是日历类 App 的通行范式
D3 时间导航三合一周切换 ▼ 与日期条合并成一行；日期条下沉为网格卡的表头，删掉网格里重复的星期行消除重复的"一二三四五六日"；日期与列天然同卡同内边距，对齐问题从根上消失
D4 设备条独立下沉2×2 四宫格 → 一条 4 联工具条（呼叫 / 上课 / 留言 / 下课），未连接时收缩为一行提示竖省约 70dp；标签从 4 字收到 2 字，扫读更快
D5 状态点 → 胶囊顶栏 10dp 圆点改为 「● 已连接」文字胶囊（绿/蓝/灰/红）10dp 圆点是不可发现控件；带文字后既可读又明确可点

顶栏高 44dp原 52dp；问候左、状态胶囊 + 设置右；居中不再放标题
「接下来」焦点卡圆角 14 / 内边距 13,14,12R_CARD；阴影 0 4 14 -8（水平偏移 0、模糊 14）
进度条高 4dp / 圆角 2轨道 ACCENT_LIGHT、填充 ACCENT
周导航行高 28dp，距焦点卡 16dp左「本周课表」15sp/600；右 ◀ 28×28 圆角 9 + 周范围 11.5sp
网格卡圆角 14 / 内边距 10,12,12距周导航行 8dp（同一信息组内）
时间列宽 36dp、行高 48dp沿用 TIME_COL_W / ROW_PITCH
课程块高 44dp / 外边距 2,1 / 圆角 4行高恒 ROW_PITCH=48，上下各留 2dp
今天列ACCENT_LIGHT 底 + 圆角 6由"整格淡蓝"升级为"列内独立底色块"，今天更明确

底栏高 62dp沿用 BAR_HEIGHT_DP

4.2 色彩（全部取自 Ui.java，无新增色）

Token浅色深色用途
ACCENT#2F6BFF#5B9BFF主色：今天列、进度、倒计时、选中 tab
ACCENT_LIGHT#EBF0FF#1A2544今天列底、图标底、进度轨道

Token字号本页用途
SP_DISPLAY22sp焦点卡课名（全页唯一最大字 = 视觉锚点；单行 + 省略号兜底）
SP_TITLE17sp放假态祝福语
SP_NUM16sp日期数字（表头）
SP_SUBTITLE15sp「本周课表」区标题

字号阶梯零新增：本方案不引入任何新字号档——全页只用既有的 7 档。焦点卡课名取 SP_DISPLAY 22sp（唯一最大字），与 15sp 区标题拉开 2 档，层级来自档位差而非「加一档 20sp」。

4.4 交互与状态

控件行为
状态胶囊（顶栏）绿 已连接 / 蓝 连接中·重连中 / 灰 未连接 / 红 连接失败。热区整颗胶囊 ≥44dp，点按 → 「手环」页
倒计时「还有 12 分钟」距下一节课开课 < 60 分钟时显示；≥ 60 分钟显示「14:00 开始」；正在上课显示「进行中 · 还剩 25 分钟」
焦点卡整体点按 → 该课详情（沿用现 showCourseDetail）
今日进度条宽 = 已完成节数 / 今日总节数；今日 0 节课时整卡降级为「今天没有课」中性态
日期格点按切换选中日（与现逻辑一致）；选中格 = ACCENT 实底 + 白字；今天 = 默认选中
周范围标签非本周时变主色「回到本周 ↩」，点按回到 weekOffset=0
设备工具条未连接 → 整条替换为「手环未连接 · 课表来自本机 / 去连接 ›」（D4）
瞬时反馈沿用现有 flashStatus：文案 2.6s 淡出，稳态不常驻
