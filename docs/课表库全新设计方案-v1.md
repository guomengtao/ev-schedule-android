# 课表库页面 · 全新设计方案 v1

> **目标页面**：底部 tab「课表库」＝ `apk/src/com/application/watch/classschedule/ScheduleListActivity.java`
> （页内顶栏原标题为「课程表管理」；用户口语亦称「课程库」）
> **交付物**：`docs/课表库全新设计原型-v1.html`（5 态高保真原型 · 1dp=1px）+ 本规范
> **画布**：手机真机 360 × 640 dp
> **日期**：2026-10-05 ｜ **状态**：待评审 ｜ **改动范围**：仅 `ScheduleListActivity.java`

---

## 0 · 一句话结论

> **这个页面真正的毛病不是"不好看"，是"信息架构错了"。**
> 三条状态条竖直叠放说同一件事、把主内容默认折叠藏起来、把不可逆的删除和编辑并排常驻、用 CheckBox 表达互斥选择。
> 所以本方案的动作是 **重排信息与操作，而不是换配色**——**全程零新增 token**。

## 1 · 现状诊断（读完 710 行源码的结论）

| # | 现状 | 为什么是问题 |
|---|---|---|
| **H1** | **三条状态条竖直叠放**：① `ConnectionBar`「已连接 · 小米手环 · v1.7.x」② `syncView` 胶囊「3 门课未同步 · 点此同步」③ `deviceBar`「● 在线 · 小米手环 ··a1b2 · 3 套 ▸」 | 三条**全宽、同形、同色系**，视觉重量完全一致 → 用户不知先看哪条。更糟的是 **① 与 ③ 说的是同一件事**（设备 + 连接状态），只是措辞不同 |
| **H2** | 一行纯说明文字：「本机保存的全部课表：可切换、编辑、同步到手环」 | **解释 UI 而不是服务用户**。占约 26dp 竖高、零可操作信息，用户点开 3 秒就懂 |
| **H3** | 分组**默认全部折叠** → 进页面只看到「▸ 本地课程 · 3 套」，**一个课表名都看不到** | 这是「库」页面，核心内容就是课表清单。默认藏起来 = 每次多点一下。**管理页应先"展示"后"操作"** |
| **H4** | 卡片右上角**常驻三图标** `[同步] 编辑 删除`，同色同大小并排 | 「删除」是**不可逆破坏性操作**却与「编辑」相邻同形无区分 → 误触风险高；且三图标把课表名挤到不足 200dp |
| **H5** | 切换当前课表用 `CheckBox「当前」` 放在卡片右下角 | **语义错误**：当前课表是**互斥单选**却用多选控件；且这是本页**最高频动作**，却用了视觉最弱、位置最偏的控件 |
| **H6** | 层级扁平：课表名 14.5sp / 分组头 12.5sp / 设备条 12.5sp / 同步胶囊 12sp 全挤在 12–14.5 | 没有明确主次，扫视时找不到锚点 |
| **H7** | 空态 = 一行灰字（12.5sp MUTED） | 新用户首屏看到一句灰话，**无插画、无主 CTA**，不知下一步做什么 |
| **H8** | 创建入口分裂：底部「＋ 新建本地课表」+ 下方「导入 / 导出」卡（EV 变体） | 三类"创建/迁移"动作分散两处，认知上是一件事 |

## 2 · 设计原则 P1–P6

页面定位：**课表库是"管理"页。** 用户来这里只干四件事 —— **看我有哪些课表 → 切换当前 → 同步到手环 → 增 / 删 / 改**。所有决策围绕这四件事排序。

| 原则 | 含义 | 落到哪个决策 |
|---|---|---|
| **P1 先展示，后操作** | 「库」的第一职责是把清单摊开给人看，而不是先让人点 | D2 分组默认展开 |
| **P2 一件事只说一处** | 设备只有一个、连接状态只有一个真相 —— 不要三条栏说同一件事 | D1 合并两栏；D3 同步态降级为徽标 |
| **P3 破坏性操作不露脸** | 删除不可逆，就不能和编辑并排常驻 | D5 溢出菜单收纳 |
| **P4 互斥用单选语义** | 当前课表只能有一套，控件语义必须匹配 | D4「设为当前」按钮 + 「使用中」徽标 |
| **P5 分层靠色彩与位置，不靠新字号** | 字号阶梯是硬规范（7 档禁增） | 全部决策 |
| **P6 零新增 token** | 落地不能牵动全局样式 | §5 映射表 |

### 七条设计决策

| 决策 | 做什么 | 解决 |
|---|---|---|
| **D1** | **`ConnectionBar` 与 `deviceBar` 合并为一条「设备条」**：左绿点 + 设备名 + `··尾号`，右「N 套」计数徽标 + 刷新图标。未连接时整条转灰 + 文案「未连接手环 · 点此连接」 | H1 |
| **D2** | **分组默认展开**；组头由厚卡降为**细行**。保留折叠能力（多设备时可收） | H3 / H6 |
| **D3** | **同步状态从页顶胶囊降级为「当前课表卡」内的徽标**：`✓ 已同步`(OK) / `3 门课未同步`(ACCENT) / `尚未同步`(WARN)，点击即同步 | H1 / H6 |
| **D4** | **当前课表用「主卡」样式**：4dp ACCENT 左竖条 + ACCENT 描边 + 标题 ACCENT 17sp + 右上「使用中」徽标。其余卡右下角给**「设为当前」描边按钮**。**删掉 CheckBox** | H5 / H6 |
| **D5** | **破坏性操作收进溢出菜单「⋯」**：编辑课表 / 同步到手环 / 从本机移除（红）。卡片右上只留一个 ⋯ | H4 |
| **D6** | **创建入口唯一化 → 顶栏 ⊕**，菜单「新建本地课表 / 导入课程表 / 导出课程表」。底部不再放常驻按钮（省 56dp 给列表） | H8 |
| **D7** | **空态补全**：线稿插画 + 「还没有课表」17sp + 说明 + 双 CTA | H7 |

### 同步徽标三态（D3）

| 条件 | 文案 | 色 | 点击 |
|---|---|---|---|
| `unsaved == 0 && isSync()` | `✓ 已同步` | `OK` / `OK_LIGHT` | 无 |
| `unsaved > 0` | `N 门课未同步` | `ACCENT` / `ACCENT_LIGHT` | 立即三向同步 |
| `!isSync()` 或 未连接 | `尚未同步到手环` / `未连接 · 无法同步` | `WARN` / `WARN_LIGHT` | 未连接 → 连接页 |

> **相对时间**：优先取 `syncedAt → CourseCache.ago()`，无值留空（不显示占位符）。

## 5 · Token 复用映射（零新增）

| Token | 值 | 用在哪 |
|---|---|---|
| `SP_TITLE` | 17sp | 顶栏标题 · **课表名** · 空态标题 |
| `SP_BODY` | 13sp | 菜单项 · 按钮文字 |
| 12.5sp（现状既有） | 12.5sp | 设备名 |
| `SP_CAPTION` | 11.5sp | 组名 · 卡片副信息 · 「设为当前」 |
| `SP_MICRO` | 10.5sp | 相对时间 · 底栏标签 |
| 11sp（现状既有） | 11sp | 计数徽标 · 同步徽标 · 「使用中」 |
| `R_CARD / R_CTRL / R_BLOCK` | 14 / 12 / 4 | 课表卡 / 设备条·按钮·菜单 / 小方块 |
| `GAP_XS/SM/MD/LG` | 4 / 8 / 12 / 16 | 卡间距 8 · 内边距 12 · 屏边距 16 |
| `TOUCH_MIN` | 44dp | ⋯ / ⟳ / 设为当前 / 菜单项 热区下限 |
| `ACCENT / ACCENT_LIGHT` | — | 当前卡 · 计数徽标 · 主按钮 · 未同步徽标 |
| `OK / OK_LIGHT` | — | 在线点 · 已同步徽标 · 使用中徽标 |
| `WARN / WARN_LIGHT` | — | 尚未同步 / 无法同步 |
| `ERR` | — | 移除菜单项 |
| `CARD / CARD2 / LINE / TEXT / MUTED` | — | 容器 / 次级底（图标钮） / 描边 / 主文 / 次文 |

**结论**：**0 个新增 token**。唯一新增视觉元素是 4dp 主色左竖条与 96dp 线稿插画，两者都用现成色值与描边宽度，**不牵动全局样式**。

## 6 · 落地清单（3 批 · 每批独立可验收）

### 批次 1 — 结构减法（低风险，纯删/合并）

- **B1.1** 顶栏 `"课程表管理"` → `"课表库"`；右侧加 ⊕ 圆钮 + 弹出菜单（D6）
- **B1.2** 删除 `ConnectionBar.attach(...)` 调用，信息并入设备条（D1）
- **B1.3** 删除说明文字「本机保存的全部课表…」（H2）
- **B1.4** `groupHeader()` 厚卡 → 细行（去背景/描边，字号降 `SP_CAPTION` + MUTED）（D2）
- **B1.5** `expandedGroups` 初始值改为"包含全部组 key"（默认展开）（D2）
- **B1.6** 删除底部「＋ 新建本地课表」按钮 + 导入/导出卡，并入 ⊕ 菜单（D6）

### 批次 2 — 卡片重排（核心）

- **B2.1** `scheduleCard()` 标题字号 14.5 → `SP_TITLE 17sp`；当前卡标题色 `ACCENT`（D4）
- **B2.2** 当前卡加 **4dp ACCENT 左竖条 + ACCENT 描边**（外层套 4dp View 或背景 drawable）（D4）
- **B2.3** `icons` 三图标 → 单个「⋯」按钮；菜单项：编辑课表 / 同步到手环 / 从本机移除（D5）
- **B2.4** 删 `CheckBox` → 当前卡显「使用中」徽标、非当前卡显「设为当前」按钮（点 → `ScheduleStore.setActive`）（D4）
- **B2.5** 副信息 `s.sub()` 拆两段：主副行（来源 · N 门课）+ 相对时间（`SP_MICRO`）
- **B2.6** `syncView` 页顶全宽胶囊 → 当前卡内同步徽标，点击行为不变（D3）

### 批次 3 — 边界与打磨

- **B3.1** 空态改插画 + 标题 + 双 CTA，按连接状态切主 CTA（D7）
- **B3.2** 未连接态：设备条转灰、隐藏计数徽标、徽标文案统一「未连接 · 无法同步」
- **B3.3** 组间 `divider()` 确认视觉后删除（细行组头自带呼吸感）
- **B3.4** `statusView` 瞬时反馈行保留（~10 处调用），上移紧贴设备条，避免与列表尾部抢位

## 7 · 风险与取舍（必须先说明，不能只报喜）

| 项 | 争议点 | 建议 |
|---|---|---|
| **B1.6** | 把「新建」从底部常驻按钮收进顶栏 ⊕，**多一次点击** | 管理页高频动作是「切换当前」而非「新建」，且 ⊕ 与首页入口一致、认知统一。若产品认为新建足够高频，可**退回底部常驻按钮**，其余决策不受影响 |
| **B1.5** | **默认展开**在多设备（3 台以上手环）时首屏会很长 | 保留分组折叠；更稳的折中是**只默认展开「当前设备组 + 本地组」**，"其它设备"组仍默认收 |
| **B2.6** | 同步徽标内嵌后，**折叠当前组即不可见** | 因 B1.5 已默认展开，实际影响很小；接受 |

## 8 · 验收标准（7 条）

| # | 验收项 | 判定方法 |
|---|---|---|
| 1 | 页面**只有一条**设备/连接状态栏 | uiautomator dump：不含 `已连接 · ` 开头的 ConnectionBar 文本 |
