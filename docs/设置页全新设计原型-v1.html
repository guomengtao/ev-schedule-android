零新增 token：本页只用到既有色值（CARD / CARD2 / ACCENT / OK / WARN / MUTED / LINE / TEXT）、既有字号档（17 / 15 / 13 / 12.5 / 11.5 / 10.5）、既有圆角（14 / 12）与既有间距（8 / 12 / 16）。并且删掉了一档字号——13.5sp（Ui.row 的唯一使用者），落地后全项目回到 7 档。
一处需要全局判断的取舍：本页原来那 6 块「灰砖」用的是 CARD2 #EAF0F8，而页面画布是 CANVAS #E9EAEF——逐通道只差 (1,6,9)，卡片边界事实上消失，只剩 1dp 描边撑着。本方案让设置页不再使用灰砖、统一走白卡，问题在本页消失；但 Ui.row() 若被其它页面继续使用，同样的「灰砖糊进背景」还会复现。建议单独立项评估这两个 token 的差值。

3设计意图速览

  • 有分组：9 个平铺入口 → 3 组（提醒 / 外观 / 支持与关于），每组一条 11.5sp 小标题。
  • 一种容器：6 块灰砖 + 3 张白卡 → 全部白卡；行标题统一 13sp，消除「入口比功能还大」的层级倒挂。
  • 重卡变行：三个「标题+开关+状态+按钮」的开关卡 → 三行开关行，副文案只说补充信息，不重复「已开启」。
  • 反馈就地：页面顶端的 resultView 删除；瞬时动作按钮自身变「已发送 ✓」，持续问题用琥珀副文案贴在该行。
  • 循环变选择：不可发现的「提前 15 分钟」循环按钮 → 设置行 + 单选弹层，一眼看全、直接选。
  • 关于归位：检查更新与版本号从屏幕两端 → 同组同卡；调试从平级 → 支持组末行。
  • 顺手收口：删掉第 8 档字号 13.5sp 与两段工程师味的 mono 实现说明。
