# EV 课程表 · 安装方式方案

> 设计日期：2026-09-28  
> 目标：为用户提供两种互补的安装通路，降低安装门槛

---

## 一、需求背景

当前 EV 课程表（手环快应用）的安装路径单一，部分用户因手机品牌/系统版本差异，遇到安装失败或操作复杂的问题。需要提供两种互补方式，确保用户至少有一条通路能成功安装。

---

## 二、两种安装方式

### 方式一（推荐）：Deck 安装版

- **地址**：[https://deck.azki.ai](https://deck.azki.ai)
- **适用场景**：手机端直接访问，一键安装
- **原理**：Deck 提供「安装版」分发能力，用户在手机浏览器打开链接即可完成安装，无需额外工具
- **优点**：
  - 操作最简单（打开链接 → 点击安装）
  - 无需安装任何辅助 App
  - 适合大多数普通用户
- **限制**：
  - 依赖 Deck 服务可用性
  - 部分系统/浏览器可能有兼容问题

### 方式二（稳定补充）：Astrobox + RPK 包

- **用户指南**：[https://app-auth.gudq.com/user-guide.html](https://app-auth.gudq.com/user-guide.html)
- **RPK 包下载**：[https://www.bandbbs.cn/resources/authors/4611408/](https://www.bandbbs.cn/resources/authors/4611408/)
- **适用场景**：当 Deck 安装版不可用或用户偏好传统方式时，作为稳定的兜底方案
- **原理**：用户安装 Astrobox App → 下载 RPK 安装包 → 通过 Astrobox 安装到手环
- **优点**：
  - Astrobox 是成熟的安装工具，兼容性好
  - RPK 包直接下载，不依赖在线服务
  - 适合进阶用户和 Deck 不可用的场景
- **限制**：
  - 需要先安装 Astrobox App（多一步）
  - 操作步骤相对较多

## 三、用户决策流程

```
用户想安装 EV 课程表
        │
        ▼
  打开安装引导页面
        │
        ├─── 推荐 ──→ 方式一：Deck 安装版
        │             打开 deck.azki.ai → 点击安装
        │
        └─── 备选 ──→ 方式二：Astrobox
                      1. 安装 Astrobox App（参考用户指南）
                      2. 下载 RPK 包
                      3. 通过 Astrobox 安装到手环
```

## 四、页面呈现

在安装引导页面中：

| 元素 | 说明 |
|---|---|
| **方式一卡片** | Deck 安装版入口，大按钮 + 简短说明，默认推荐 |
| **方式二卡片** | Astrobox 方案，包含用户指南链接 + RPK 下载链接 |
| **状态栏图标** | 页面 favicon，品牌标识（32×32 / 64×64） |
