# 首页精修四期评估：还有没有值得修的？

> 日期：2026-09-30。前序：一期（字阶/字重/课程块）、二期（图标语义/控件同框/note 去重）、三期（周导航矢量图标/图标尺寸对齐）。
> 本文档回答一个问题：**首页还需要精修吗？**
> 结论先行：**核心问题已清零，建议进入"观察期"**；剩余候选项里只有 2 个小项值得做，其余明确不做或等反馈。本文档本身是分析任务，不做代码改动。

## 2. 剩余候选项评估

### 2.1 值得做（小，合计 ≤4 积分，可与下个需求顺车）

| # | 项 | 理由 | 量级 |
|---|----|------|------|
| 1 | **日期条 elevation 统一**：日期条格子 elevation 4、网格卡 elevation 6（一期遗留 P11 半完成） | 阴影方向/深度不一致在浅色下可见；统一为卡片 0 + LINE 描边或全部 4 | 3 行 |
| 2 | **无障碍描述补齐**：日期条格子无 contentDescription（"周一 9月28日 休"），读屏用户不可用；周标签同理 | 无障碍是精修的应有之义，改动纯增量 | 8 行 |

### 2.2 观察后定（不主动做，等日常使用反馈）

| 项 | 触发条件 |
|----|---------|
| 错误卡折叠（默认一行，点开展开按钮区） | 错误卡长期占据一屏 1/4 高度引起抱怨时 |
| greeting「Hi，同学」→「第 N 周 · 周X」 | 用户觉得问候无信息量时（属信息架构变化，需用户拍板） |
| 日期条与网格表头合并（一期方案 B） | 翻周/今天药丸/休班 badge 三套逻辑想清楚后 |
| Today/Next 插件视觉对齐（块高/圆角与首页一致） | 插件截图与首页并排对比后觉得割裂时 |
| 深浅主题逐屏截图自动化对照 | 回归频率提高、手动对照嫌烦时 |

### 2.3 明确不做（有结论的关闭项）

| 项 | 结论 |
|----|------|
| 4 字课名窄列完整显示 | **物理不可解**（列宽 38dp 实测推导，三期文档），走 [单] 模式 |
| 日期条与表头合并 | 职责已清晰（上=日期、下=星期），合并收益不抵风险 |
| 假期列配色再调 | 两轮调整后已达标，再调无增量 |
| 精确时间轴 | 数据模型只有时间字符串，无节次轴，强做会失真 |

## 3. 预算复盘（本期规定的执行检讨）

三期实际 **16.62 积分（超限 6.62）**，超支点：

1. **ScaleDrawable 方案失效**（-1 轮返工）：自绘/系统行为类改动预估时没按"不确定性 ×2"计
2. **4 字截断多轮验证**：先后试了 padding 2、课名 10、9.5 三种组合才确认是列宽物理约束——**第二次未通过时就应停止并降级**
3. 顺手扩大改动面（margin 四向化、教室行放宽）未计入初始预算

**后续执行规则（已写入工作记忆）**：估分按不确定性翻倍；同一项返工第二次未过立即降级或放弃；不顺手扩面；超限即收尾汇报。

---

## 4. 建议

1. **首页视觉精修到此收束**：三期覆盖的维度（字阶/字重/对比度/图标语义/信息去重/状态互斥）已构成一个自洽的规范，继续主动找活干会进入收益递减区
2. 2.1 表里两个小项（elevation 统一 + 无障碍描述）留给下一个顺车需求，不单开任务
3. 后续首页改动改为**反馈驱动**：真机用起来 → 截图对比发现具体别扭点 → 单点修 → 一轮编译。不再开"整体精修"式任务
4. 沉淀成果：三期文档 + 本文档可作为后续任何 UI 改动的规范依据（字阶 token、图标尺寸规则、对比度公式、留白节奏都在其中）
