# 手机 App 首页 · 全新设计方案 v1

> **对象**：Ev 课程表 Android 端首页（`HomeActivity`，EVSyncProbe）
> **画布**：360 × 640 dp（真机 BLN-AL20 `1080×1920 @480dpi`）
> **配套原型**：`docs/首页全新设计原型-v1.html`（1 dp = 1 px，四态高保真）
> **基线**：v0.5.143（2026-10-05）· 上承 `docs/首页UI设计优化方案.md`（精修四期已全部落地）
> **性质**：**纯设计方案（不改任何代码）**。落地时按 §6 清单分批执行，每批可独立验收。

---

## 0. 一句话主张

> **首页只回答两件事：「我现在该干嘛」和「这周什么样」。其余一律降级。**
>
> 现有首页是「8 个等权区块的平铺」——不是不好看，是**没有层级**。本方案的核心动作是**重新分配视觉权重**，而不是重新配色。

## 1. 设计原则（本页所有决策的依据）

| # | 原则 | 在本页的体现 |
|---|---|---|
| P1 | **一个屏一次「一眼」** | 焦点卡课名是唯一 22sp 大字，其余全部 ≤17sp；视线永远有第一落点 |
| P2 | **信息只说一遍** | 删掉第二份「一二三四五六日」、删掉 App 名标题、删掉重复的课表名/节数 |
| P3 | **位置即语义** | 「今天」靠列底色 + 选中格实底表达，不靠文字标注 |
| P4 | **高频优先** | 最高频问题（下一节课）放在最高位置；低频动作（导出/导入）沉进 ⊕ 菜单 |
| P5 | **零新增 token** | 颜色、字号、圆角、间距**全部复用 `Ui.java` 既有 token**，不引入新档 |
| P6 | **可达性内建** | 所有热区 ≥44dp；文字对比度 ≥4.5:1；状态不靠颜色单一通道表达（胶囊带文字） |

### 2.2 删掉的东西（都是"重复"，不是"功能"）

- ❌ 顶栏「Ev课程表」标题 —— App 名对用户零信息量，且与「本周课表」构成双标题。
- ❌ 网格卡内的「一二三四五六日」表头行 —— 与日期条完全重复，合并进表头即省 ~34dp。

## 3. 焦点卡「接下来」——本方案的核心新增

### 3.1 为什么是它

用户打开课表 App 的第一句话不是"这周有什么课"，而是**"我下一节课是什么、还有多久、在哪"**。现有首页需要用户在 7×N 小格子里"找到今天那一列、再从上往下扫"——这是**两次定位**。焦点卡把它变成**一次阅读**。

这也与主流日历/课表 App 的范式一致（Google Calendar 的 "Next up"、系统锁屏的"下一个日程"），符合用户既有习惯。

### 3.2 三态定义

| 状态 | 触发条件 | 卡内内容 |
|---|---|---|
| **有下一节课** | 今天还有未开始的课 | 小字「接下来 · 第 N 节 10:00–11:35」+ 课名（22sp）+ 地点·教师 + 倒计时 + 今日进度条 |
| **正在上课** | 当前时刻落在某节课区间内 | 小字「**进行中** · 第 N 节 10:00–11:35」+ 课名 + 地点·教师 + 「还剩 25 分钟」+ 进度条 |
| **今天没课 / 放假** | 今日 0 节，或命中假期 | 中性态：「今天没有课」/ 假期态：祝福卡（复用 `Holiday.greeting()`，绿底） |

### 3.3 倒计时文案规则

| 距开课 | 文案 |
|---|---|
| 0（进行中） | `还剩 25 分钟` |
| ≤ 60 分钟 | `还有 12 分钟` |
| > 60 分钟 | `14:00 开始` |
| 已上完当天所有课 | 卡片顶部小字改「今天的课都上完了 🎉」，主行显示最后一节 |

## 4. 组件规格

### 4.1 顶栏（44dp）

```
┌───────────────────────────────────────────────┐
│ Hi，小明          [● 已连接]        [⚙ 32×32] │   padding 0 16
└───────────────────────────────────────────────┘
   13sp/400          11.5sp/500 胶囊          R 10dp
   名字 13sp/600
```

| 元素 | 规格 |
|---|---|
| 问候「Hi，小明」 | `SP_BODY 13sp`；「Hi，」`MUTED` + 名字 `TEXT/600`；`maxWidth 150dp` + 省略号 |
| 状态胶囊 | `SP_CAPTION 11.5sp/500`，`padding 4×9`，`圆角 999`（全圆）；内含 7dp 圆点 |
| 胶囊配色 | 已连接 `OK / OK 12%`·连接中 `ACCENT / ACCENT_LIGHT`·未连接 `MUTED / MUTED 14%`·失败 `ERR / ERR 12%` |
| 设置钮 | `32×32`，`圆角 10`，底 `CARD2`，图标 17dp `MUTED`；**热区扩到 44dp**（`ensureTouch`） |

> **热区纪律**：胶囊与设置钮的**可点区域都要 ≥44dp**——视觉可以小，热区不能小（现有 ⊕ 已用此手法）。

### 4.2 「接下来」焦点卡

| 项 | 值 |
|---|---|
| 容器 | 底 `CARD`、描边 `LINE`、圆角 `R_CARD=14`、内边距 `13,14,12,14` |
| 阴影 | `elevation 4dp`（与网格卡同级，形成"两张主卡"） |
| 小字行 | `SP_CAPTION 11.5sp`；`MUTED` + 节次/时间用 `ACCENT/600`；右侧倒计时 `ACCENT/600` |
| 课名 | `SP_DISPLAY 22sp/600`，`LH_DISPLAY 1.27`，单行 + 省略号 |
| 副行 | `SP_BODY 13sp`，`MUTED`，格式 `地点 · 教师`（分隔点用 `LINE` 色） |
| 进度条 | 高 4dp、圆角 2；轨道 `ACCENT_LIGHT`、填充 `ACCENT`，宽 = 已完成/今日总数 |
| 进度说明 | `SP_MICRO 10.5sp`，左「今日进度 3 / 5 节」右「11:35 下课」 |
| 放假态 | 底改 `OK_LIGHT`、无描边；祝福语 `SP_TITLE 17sp` + `OK`；副行 `假期名 · 今天没有课` |

### 4.3 周导航行 + 网格卡（时间导航三合一）

```
本周课表                          [◀] 9.29–10.05 [▶]      ← 28dp，距焦点卡 16dp
┌──────────────────────────────────────────────────────┐
│        │ 一  二  三  四  五  六  日                    │   ← 表头=日期条（36dp spacer + 7 列）
│        │ 29  30  1   2  [3] 4   5                     │     选中列 ACCENT 实底 + 白字
│ 08:00  │ ▉           ▉   ▉                            │
│ 10:00  │ ▉   ▉       ▉  ▉                            │   ← 行高恒 ROW_PITCH 48dp
│ 14:00  │     ▉   ▉       ▉                            │
└──────────────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 周导航行 | 高 28dp；「本周课表」`SP_SUBTITLE 15sp/600`；◀▶ 各 `28×28 / 圆角 9 / 底 CARD2`（热区 44dp）；周范围 `SP_CAPTION 11.5sp MUTED` |
| 非本周 | 周范围变 `ACCENT/600` + 「回到本周 ↩」，整块可点 |
| 网格卡 | 底 `CARD`、描边 `LINE`、圆角 14、内边距 `10,12,12,12`；`elevation 4` |
| 表头 | 36dp spacer + 7 列等分（`weight=1`）；星期 `SP_MICRO 10.5sp MUTED`、日期 `SP_NUM 16sp/600 TEXT` |
| 选中格 | `ACCENT` 实底矩形（`inset 0 2dp`, 圆角 10）+ 白字 —— 替换原「非选中白卡/选中蓝卡」的双卡结构，去掉了 7 张卡片的阴影噪声 |
| 休/班角标 | 14×14、圆角 4、`SP_MICRO`；休=`OK/OK_LIGHT`、班=`WARN/WARN_LIGHT`；**右上角绝对定位**（不与星期字拼读） |
| 时间列 | 宽 36dp（`TIME_COL_W`）；行高 48dp（`ROW_PITCH`）；`SP_MICRO 10.5sp MUTED` |
| 课程块 | 高 44dp（`BLOCK_H_2LINE`）、外边距 `2,1`、圆角 `R_BLOCK=4`；两行 = 课名 `SP_CAPTION 11.5sp/600` + 地点 `SP_MICRO 10.5sp` |
| 课块字色 | 沿用 `Ui.onCourseColor()`（亮度 0.45 阈值自动深/白） |
| 当前节 | `ACCENT` 2dp 描边（`outline` 内缩 2dp），保留现逻辑 |
| 今天列 | `ACCENT_LIGHT` 列底色 + 圆角 6 —— 由"整格淡蓝"升级为"独立列色块"，今天更明确 |

> **对齐保证**：日期条与天列**同属一张卡、同一内边距**，横坐标天然一致，不需要再靠"让出 48dp"去凑（§3.2 的老办法可以退休了）。

### 4.4 设备工具条

| 项 | 规格 |
|---|---|

### 4.5 底栏

沿用现有 62dp 四 tab（`Ui.bottomBar`），**仅改一处文案**：

| 位置 | 现状 | 改为 | 原因 |

## 7. 取舍与风险

| 项 | 说明 |
|---|---|
| **不做** | 不引入底部抽屉、不做手势导航（如左滑切周）——会与系统返回手势冲突，且用户无此习惯 |
| **保守** | 主视觉仍是**周课表网格**（不动它），焦点卡是"叠加"而非"替换"——用户找不到课表的风险为零 |
| **待定** | 底栏 tab 改名（§4.5）需产品确认；若不动，首页与 tab 的语义重叠会保留 |
| **风险** | 焦点卡的"下一节"依赖准确时间数据；若课表时间字段不规范，倒计时会失真 → 建议 `CourseCache.minutes()` 返回 null 时**隐藏倒计时而非显示 0** |
| **视觉中性** | 本方案不改变品牌色，也不做"炫技"渐变——目标是**耐看、可维护、可扩展**，而非一次性的视觉冲击 |

## 8. 与上一版方案的关系

`docs/首页UI设计优化方案.md`（精修四期）解决的是**「同一套结构里的皮肉问题」**：块间距、圆角、行高对齐、角标误读、问候占行。
本方案解决的是**「结构本身」**：信息层级、重复信息、最高频问题的落点。

两者**不冲突**：本方案完全建立在精修四期的成果之上（`ROW_PITCH 48`、`R_BLOCK 4`、`BLOCK_H_*`、`onCourseColor` 全部沿用），是在"已经把细节磨好了"的地基上，重排一次骨架。
