一句话结论：本页真实用户只有两种 —— A 已付款拿码来激活（多数，且可能由深链直达）、B 还没付款来看怎么买（少数）。 现状把 B 的需求（买码卡）放在 A 的需求（输入卡）前面，且同一件事（连没连上手环）被三个地方各说了一遍。

01被删掉的东西（对照现状）

  • 顶栏副标题「一键激活：只需填 4 位兑换码」—— 与卡内标题重复说「4 位」。
  • ConnectionBar 整条 —— 与设备卡状态、设备 ID 三处同时说「没连上手环」。
  • resultView 裸文本 —— 深链提示 / 呼叫反馈 / 激活全过程三合一，且与 statusView 构成两套反馈通道。
  • Ui.mono 两段等宽说明 —— 硬前提「需装小米运动健康」被埋在最底部。
  • 「① ②」编号 —— 4 步流程只编两个号，中间夹一张无编号的设备卡。

04规格速查

四格尺寸校验：屏宽 360dp − 页面边距 40（20×2） − 卡内边距 28（14×2） = 292dp 可用； 四格 4×56 + 3×8 = 248dp，余量 44dp ✓（现状 54×4 + 10×3 = 246dp，其中 10 不在 4dp 栅格上）。
零新增 token：字号只用到 SP_TITLE 17 / SP_BODY 13 / SP_CAPTION 11.5 / SP_MICRO 10.5 / SP_DISPLAY 22； 圆角只用到 R_CARD 14 / R_CTRL 12；间距只用到 GAP_SM 8 / GAP_MD 12。 顺带消除越界字号 24f（第 9 档）。
唯一一处新增行为：成功卡的「回首页」按钮（startActivity(HomeActivity)）。其余全部为视图层改动 —— 激活 / 暂存 / 续传 / 深链 / 埋点逻辑零改动。
