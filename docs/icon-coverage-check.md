# admin_Dx23.html 图标覆盖与遗漏分析

> 目的：核验 `app-auth/admin_Dx23.html` 中所有“文字 / emoji / 符号图标”是否都已纳入
> `tools/inject_lucide_mapper.py` 的映射表（`GLYPHS`），核实是否存在**遗漏**的图标。
> 运行审计脚本：`python3 tools/report_missed_icons.py`

---

## 一、分析方法

对目标文件逐字符扫描，识别落在“符号 / 表情 / 几何 / 箭头”等 Unicode 区段的字形，
统计其在文件中的出现次数，再与映射表 `GLYPHS` 中的键做差集：

- **已覆盖**：字形在映射表中 → 运行时会由该字符生成对应的 lucide 图标。
- **遗漏（未覆盖）**：字形出现在文件中、但不在映射表中 → 仍会以原生 emoji 显示。

参与的 Unicode 区段：`2190–21FF(箭头)`、`2300–23FF(技术符号)`、`2500–25FF(几何)`
、`2600–26FF(杂项符号)`、`2700–27BF(杂项字形/dingbats)`、`2B00–2BFF(杂项箭头)`、
`1F000–1FAFF(Emoji)` 等。（`FE00–FE0F` 变体选择符与所在表情合并统计，不单列。）

## 五、实现与回滚说明

- 统一方案：运行时 DOM 映射（`<i data-lucide>` + `lucide.createIcons()`），
  零 JS 语法风险，覆盖静态与动态渲染。
- 注入脚本 `tools/inject_lucide_mapper.py` **幂等**：再次运行会精确移除旧的
  `data-lucide-mapper` 脚本块与 `.lucide-inline` 样式，再注入最新映射（保留映射表更新能力）。
- 每次运行都会生成带时间戳备份 `admin_Dx23.html.bak-<时间>`。当前有效备份：
  - `admin_Dx23.html.bak-20261001-231837`
  - `admin_Dx23.html.bak-20261001-233213`

> ⚠️ QA 记录（一次性故障）：早期版本注入脚本的“移除旧块”正则使用了跨过整个
> `<head>` 的 `[\s\S]*?` 匹配，曾导致文件被误删至约 5.5KB。已改用**精确定位**的锚点
> 表达式从备份恢复重建，并保持文件完整（约 586KB）。当前脚本已无此问题。

## 六、后续维护建议

1. 新增页面交互图标时，务必先查 `https://lucide.dev/icons/` 选用现有图标；
2. 若手动在 HTML/JS 中又加入了新的 emoji / 符号图标，重跑
   `python3 tools/inject_lucide_mapper.py` 即可自动纳入（幂等）；
3. 用 `python3 tools/report_missed_icons.py` 定期复核是否有遗漏的真实图标。
