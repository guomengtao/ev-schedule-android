## 3. 设计原则

1. **一眼锁定「现在与下一节」**：周视图是全周地图，但首页第一眼应该回答"现在干嘛、下节是什么"。现状做不到（无今日/当前节强调），精修后用「今天列 + 当前节描边」补足
2. **信息只说一遍**：今天、星期、连接状态，各只留一处主表达
3. **字阶收敛为 6 档**，全部走 `Ui` token，页面不再裸写 sp
4. **中文不加粗，用 Medium 字重**：`Typeface.create("sans-serif-medium", NORMAL)` 替代 `setFakeBoldText`/`bold`——这是全 App 一次性提质最大的改动
5. **间距 4dp 网格**：全部取 4/8/12/16/20/24

### 4.1 字阶 Type Scale

| Token | 值 | 用途 |
|-------|----|----|
| `T_DISPLAY` | 26 | 大标题「本周课表」 |


### 5.1 Before → After 对照

| 项 | 现值 | 新值 | 理由 |
|----|------|------|------|
| 课程块高 | 40 | **44** | 容纳两行字不挤 |

| 块圆角 | 8 | **10** | 与 R_BLOCK 一致 |

| 块内教室（新增） | 无 | **9 micro**，白 75% / 深字 65%，仅写地点 | 修 P9 |

| 时间列字号 | 9 | **10** | 修 P1 同源问题 |
| 时间列宽 | 30 | **34** | "10:00" 不贴边 |

### 5.2 精修后色块结构（ASCII）

```
现状（40dp，1 行）：          精修（44dp，2 行）：
┌──────────┐                ┌──────────┐
│ 高等数学  │ 9.5bold 白     │ 高等数学  │ 10.5 medium · 高对比字色
└──────────┘                │ A301     │ 9 · 65~75% 透明
                            └──────────┘
```

### 5.3 块内字色公式（新增 `Ui.onCourseColor(int bg)`）

```java
// 相对亮度 > 0.45 的底色（橙/绿/青/粉）→ 深字 0xFF0F172A 系
// 否则白字；透明度统一：主字 FF，副字 CC
int luminance = 计算(bg);
return luminance > 0.45 ? 0xFF101828 : 0xFFFFFFFF;
```

调色板**不动**（品牌色辨识度保留），只按公式换字色——零风险拿到对比度达标。

### 5.4 「两排星期」的取舍（修 P4）

- **方案 A（推荐，本期做）**：日期条保留（日期数字是独有信息），网格表头退化为纯「一二三四五六日」10.5sp——两排各有职责（上=日期，下=星期），仅统一字号与对齐
- **方案 B（二期可选）**：合并——把日期条做成网格的表头（周一 9.28 格子直接当列表头），网格卡上移一行。视觉最干净，但要处理今天药丸/休班 badge/翻周三套逻辑，改动大，等 A 落地后看观感再定

## 9. 风险与边界

| 风险 | 应对 |
|------|------|
| medium 字重在部分老 ROM 上缺失 fallback | sans-serif-medium 是 AOSP 标准字重，API 24+ 全覆盖；fallback 自动落 regular |
| 课程块加教室后小屏溢出 | 教室行 ellipsize(6)，高度不够（<40dp 列宽）时只画课名（与编辑网格同一策略） |
| onCourseColor 换字色后与插件配色不一致 | WeekWidget/TodayWidget 用同一 `Ui.onCourseColor`（插件 RemoteViews 同样适用） |
| 移除包名行影响排障 | 设置页「关于」补一行同信息；文案 grep 无依赖 |
| 当前节描边依赖 minutes() 解析 | 解析失败（非标时间）就退化为无描边，无副作用 |

## 11. 总结

1. **最大单点**：中文伪粗体 → sans-serif-medium；裸 sp → 6 档字阶 token（修 P2，全局受益）
2. **课程块**：44dp 双行（课名+教室）、按底色亮度选字色（5/7 色对比度从不达标到达标）、圆角 10、margin 2
3. **做减法**：今天三处表达留一处、包名行移除、连接状态只显示一条、note 弃 mono
4. **网格对齐系统**：时间列行高与块高对齐、34dp 列宽、表头 10.5 与日期条同级
5. 二期再评估日期条与表头合并（方案 B），本期以低风险精修为主
