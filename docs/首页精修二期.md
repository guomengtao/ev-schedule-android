## 1. 点名需求 A：课表名图标换成「切换」语义

### 1.1 现状与问题

课表名行：`📅 手环课表`，点击进入**课程表管理页**（唯一用途=切换/管理课表）。日历图标表达的却是"日历/日期"，与行为无关——图标语义错位。

### 1.2 方案：Lucide「repeat」（循环切换）

代码替换点（`HomeActivity.renderWeek` 内 nameLine 一处）：

```java
// 旧：ic_tab_schedule（日历）
```

染色逻辑不变（`setColorFilter(ACCENT)`）。备选图标：`arrow-left-right`（左右交换）——repeat 的"循环回来"语义更贴"在多套课表间切"，取 repeat。

## 2. 点名需求 B：[单] 与 ✏️ 外框同尺寸

### 2.1 现状

批次 2 统一了高度 30dp，但**宽度不等**：[单] 是 wrap_content（约 44dp 宽的横长条），✏️ 是 30×30 方块——并排看一边宽一边方，不成组。

### 2.2 方案：两个都固定 30×30 正方

```java
// [单]：30×30 定宽定高，文字居中，去水平 padding
LinearLayout.LayoutParams slp = new LinearLayout.LayoutParams(
        Ui.dp(this, 30), Ui.dp(this, 30));   // 原 WRAP_CONTENT
slp.leftMargin = Ui.dp(this, 8);
singleBtn.setPadding(0, 0, 0, 0);             // 原左右 12dp
nameRow.addView(singleBtn, slp);
```

✏️ 已是 30×30 不动。圆角同 14、底色同 CARD2/LINE，成组后视觉完全对称。

## 3. 自查改进项（对照 v0.5.102 夜间真机截图）

### 3.1 note 行信息去重（收益最高的一处）

现状：`来自手环 · 6 门课 · 最后同步：1 小时前 · 更新于 1 小时前`——对 sync 课表，"最后同步"与"更新于"是同一件事说两遍。

方案：sync 课表只保留「最后同步」；local 课表保留「更新于」：

```java
String note;
if (s.isSync()) {
    note = "来自手环 · " + s.courses.size() + " 门课 · 最后同步 " + CourseCache.ago(s.syncedAt);
} else {
    note = "仅本机 · " + s.courses.size() + " 门课 · 更新于 " + CourseCache.ago(s.createdAt);
}
```

（`Schedule.sub()` 列表页仍用双信息，列表页有分隔语境不算重复；只改首页。）

### 3.2 日期条「休/班」badge 暗色变体（一期遗留）

日期条非选中格的「休」目前随 MUTED 灰字，语义弱。对齐网格表头的做法：非选中 + badge 时字色用主题变体（暗底 `0xFF7BD88F` / `0xFFFFC53D`，浅底 `0xFF16A34A` / `0xFFD97706`）。实现：日期条星期行从单 TextView 拆「星期 + badge」两个 Span（`SpannableString` + `ForegroundColorSpan`），badge 部分单独上色。

### 3.3 课程块双行行距

44dp 块内课名(10.5)与教室(9)两行目前零行距，略挤。课名 TextView 加 `setLineSpacing(dp(1), 1f)` 并把块内 padding-top 减 1dp，视觉居中不变。

### 3.4 错误卡行距

错误卡长文案（两行 WARN）行距紧。`hintView.setLineSpacing(dp(2), 1f)`，并在文案前保留图标位（现有布局已可）。

### 3.5 假期列底色再淡一档

暗色主题 `0x1F2FBF6A` 实测仍偏重（截图里绿色块感明显，与课程块争视觉）。降到 `0x142FBF6A`（与浅色同透明度档），文字亮度不变，靠字色区分即可。

### 3.6 日期条与网格卡间距

`weekBox.addView(Ui.space(this, 4))` 4dp 偏挤（日期条格子 elevation 与网格卡贴着）。改 **8dp**，让两个卡片呼吸开。

| repeat 图标 14dp inset 后过小 | inset 顶部垫 2dp 保持视觉居中；染色逻辑沿用现成管道 |
