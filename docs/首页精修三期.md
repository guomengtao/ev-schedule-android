## 1. 点名需求 A：周导航 ‹ › 符号太小

### 1.1 现状

二期把 ‹ › 从 18sp 压到 14sp——文字字符本身字形小（字符面约占 60%），32dp 圆钮里显得空且小，点击目标与视觉尺寸不匹配。

### 1.2 方案：文字字符 → 矢量图标（一步到位）

字符符号的固有缺陷：基线不齐、字重不可控、跨 ROM 字形差异。改用项目现成的 Lucide 矢量：

- 左箭头：`ic_chevron_left`（**已有**）
- 右箭头：新增 `ic_chevron_right.xml`（Lucide chevron-right：`m9 18 6-6-6-6`，同规格 24×24 描边 2）

```xml
<?xml version="1.0" encoding="utf-8"?>
<!-- Lucide "chevron-right" 24×24 描边 2，运行时染色 -->
<vector xmlns:android="http://schemas.android.com/apk/res/android"
    android:width="24dp" android:height="24dp"
    android:viewportWidth="24" android:viewportHeight="24">
    <path
        android:pathData="m9 18 6-6-6-6"
        android:strokeColor="#FF000000"
        android:strokeWidth="2"
        android:strokeLineCap="round"
        android:strokeLineJoin="round"
        android:fillColor="#00000000"/>
</vector>
```

按钮改 `ImageView`（18dp 视觉尺寸，32dp 圆钮不变，tint MUTED）：

```java
ImageView prevBtn = new ImageView(this);
prevBtn.setImageResource(R.drawable.ic_chevron_left);
prevBtn.setColorFilter(Ui.MUTED);
prevBtn.setPadding(Ui.dp(this, 7), Ui.dp(this, 7), Ui.dp(this, 7), Ui.dp(this, 7));
prevBtn.setBackground(Ui.round(Ui.CARD2, 15, 0, this));
prevBtn.setContentDescription("上一周");
// nextBtn 同理，ic_chevron_right
```

图标实际视觉 ≈18dp，比 14sp 字符（≈10dp 视觉）大近一倍，且按压区仍是 32dp 全格。

## 2. 点名需求 B：课表名前 repeat 图标不能比文字高

### 2.1 现状

`ic_repeat` 本征 24dp，而"手环课表"文字只有 13sp（行高约 17dp）——compound drawable 用的是本征尺寸，图标明显高出文字一截（真机截图可见）。

### 2.2 方案：ScaleDrawable 缩到 16dp（不新建资源）

compound drawable 无法直接 setBounds，用标准 `ScaleDrawable` 技巧把 24dp 缩到 72%（≈17dp，与 13sp 文字行高齐平）：

```java
// 缩放版 repeat：24dp → 72% ≈ 17dp，与 13sp 文字同高
Drawable rep = new android.graphics.drawable.ScaleDrawable(
        getDrawable(R.drawable.ic_repeat),
        android.view.Gravity.CENTER, 0.72f, 0.72f);
rep.setLevel(10000); // ScaleDrawable 必须 setLevel 才绘制
android.graphics.drawable.Drawable listIc =
        new android.graphics.drawable.InsetDrawable(rep, 0, Ui.dp(this, 1), 0, 0);
```

垂直 inset 1dp 微调视觉居中。染色（setColorFilter ACCENT）沿用现有管道不受影响。

## 3. 自查改进项（对照 v0.5.102 浅色真机截图）

### 3.1 课程块 4 字课名截断（最有价值）

窄列下"高等数学"显示成"高等数…"——列宽 47dp，10.5sp × 4 字 ≈ 44dp，加块内左右 padding 3dp×2 后放不下。

方案：块内左右 padding **3→2**、课名 **10.5→10**：4 字 ≈ 40dp + padding 4dp = 44dp < 47dp ✓ **4 字课名完整显示**（"高等数学""数据结构""线性代数"都不再截断）。教室行 9sp 同步放宽 ellipsize 到 7 字。

### 3.2 日期条 gap 与网格列 gap 统一

日期条格间 4dp、网格列间 3dp（3.4 期遗留）。统一为 **4dp**：网格 `gap` 变量 3→4，块间 margin 2 不变，视觉横向节奏一致。

### 3.3 大标题图标同步收紧

`📅 本周课表` 的日历图标 26sp 行里显示原尺寸（24dp），与 repeat 同病的反向案例（大字配大图标，正确）。确认**保持不动**，仅记录：图标尺寸跟随字号的原则——字号 ≥20sp 配 24dp 图标，13~17sp 配 16~18dp。

### 3.4 周标签点击区

「9.28-10.4」12sp 文字点击区太薄（一行文字高）。加 `setPadding(0, dp(8), 0, dp(8))`，点按区扩到 ≈36dp 高，与 ‹› 圆钮齐平。

### 3.5 底栏选中态文字

选中 tab 标签 10.5sp 仍是 bold（中文伪粗体）——首页 body 都已 medium 化，底栏漏网。`Ui.buildBar` 里标签选中时改 `textMedium`。

## 6. 风险

| 风险 | 应对 |
|------|------|
| ScaleDrawable 染色失效 | setColorFilter 作用在 InsetDrawable 外层会透传到子层；若实测不生效则把 colorFilter 设在 ScaleDrawable 内层包的原始 drawable 上 |
| 课名 10sp 后单字模式 16sp 不变 | 单字模式走独立字号分支，不受影响 |
| chevron 18dp 在 32dp 圆钮内偏小 | padding 7dp 对称，视觉居中；不满意微调 padding 6dp（图标 20dp） |
