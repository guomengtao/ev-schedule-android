# 底部导航统一改版 + 顶栏居中标题 —— 需求整理

> 2026-09-28 · 状态：**需求确认中（未实施）**  
> 关联：`docs/首页美化方案.md`（上一轮，底栏「选中纯色无背景」的规则将被本需求**推翻**）

---

## 一、需求原文（用户，2026-09-28）

> 设置页底部菜单第三个位置加入一个「导入」新按钮，连接我们已有的导入页面。底部一共四个了，选中后按钮填充为实心的，不仅仅是线框变了颜色。首页的底部也换成设置页那种底部菜单，原来的去掉。底部菜单就统一都是 4 个了，一样。底部四个菜单（页面）顶部都加入一行表头，标题居中显示，颜色配合风格显示。其他页面也是一样，标题也居中，但是多了一个返回按钮。

## 二、需求解读（逐条）

### R1 · 底栏统一为 4 个 tab

| 位置 | Tab | 页面 | 说明 |
|---|---|---|---|
| 1 | 首页 | `HomeActivity` | 现有 |
| 2 | 课程表 | `ScheduleListActivity` | 现有 |
| 3 | **导入**（新增） | `TransferActivity`（mode=import） | 连接已有导入页；原第三位「设置」顺移到第 4 |
| 4 | 设置 | `SettingsActivity` | 现有 |

- 首页现在用的**胶囊底栏（pillBar：课表/周视图/消息/设置）整体弃用**，与设置页的普通底栏合并为**唯一一套** 4-tab 底栏（`Ui.bottomBar` 改造）。
- EvBox 变体的 legacy 首页（`buildLegacyUi`）同样跟随新底栏。

### R2 · 选中态 = 实心填充

- 选中 tab：**实心填充**（主色 ACCENT 圆角块背景 + 白色图标/文字），不再是「仅变色」。
- 未选中 tab：线框色（MUTED 图标/文字），无背景。
- ⚠️ 此条**推翻** `docs/首页美化方案.md` 中「选中永不加背景」的约定——以本需求为准，并在首页美化方案文档中同步更正。

### R3 · tab 页顶部加居中表头

- 4 个 tab 页顶部各加一行**表头标题，水平居中**，颜色随主题 token（TEXT），如「首页」「课程表」「导入」「设置」。
- 原 `Ui.title()` 裸标题被替代；首页的「本周课表」大标题行、周切换器等**保留在表头之下**（表头是页面级导航条，不替代页内内容标题）。

### R4 · 子页标题居中 + 返回按钮

- 所有非 tab 子页（导入/导出、留言、调试、JSON 编辑器、高级版、主题外观、打赏支持、省电白名单、首页设置）：
  - 标题**居中**（原为左对齐）；
  - **返回按钮（chevron-left）固定在左侧**，与标题同行；
  - 布局建议：FrameLayout/三段式——返回键绝对居左，标题绝对居中，右侧对称占位保证视觉居中。

## 三、待拍板的歧义点（实施前需确认）

| # | 问题 | 建议 |
|---|---|---|
| Q1 | 「导入」tab 直达 `TransferActivity` 的**导入模式**，那「导出」入口还剩课程表页的「导出课程表」按钮——是否需要在导入页内做 导入/导出 分段切换？ | 建议：底栏只进导入模式；页内顶部加「导入 / 导出」分段开关，一个页面两个用途 |
| Q2 | 原 pillBar 里的「**消息**」tab 取消后，留言页只剩首页「发消息给手环」间接可达——是否在首页快捷区补一个「留言」入口？ | 建议：首页快捷操作区补一行「留言」按钮，否则留言页成为孤页 |
| Q3 | 原 pillBar 的「**周视图**」tab 即首页自身，取消无影响——确认无需单独周视图页？ | 确认即可 |
| Q4 | TransferActivity 从子页变为 tab 页：**去掉返回键**（tab 页规则），其「导入/导出」动态标题改为固定「导入」（若采纳 Q1 分段开关则标题随分段变） | 采纳 Q1 方案则自然解决 |
| Q5 | 实心填充的形状：普通底栏（无胶囊容器）上选中块用圆角矩形（类似旧 pill 的 26dp 圆角）还是整块填充？ | 建议：圆角矩形填充（ACCENT，圆角 12~14dp），视觉与卡片圆角语言一致 |

## 四、实施清单（确认后执行）

1. `Ui.bottomBar`：tabs 改 4 个（首页/课程表/导入/设置），选中态实心填充（ACCENT 圆角块 + 白色前景），未选中 MUTED；`pillBar` 及 `wrapWithPillBar/fixedWithPillBar` 删除或废弃。
2. `Ui.header`：布局改为「返回键居左 + 标题居中」三段式。
3. 新增 `Ui.topBar(Activity, String title, boolean showBack)`：tab 页（showBack=false）与子页（true）统一走它，替代 `Ui.title`。
4. `HomeActivity`：pillBar 调用换新底栏（current=0）；`ScheduleListActivity` current 1；`SettingsActivity` current 3；`TransferActivity` 以 tab 形态接入（current=2，无返回键，按 Q1 加分段）。
5. 各 tab 页顶部加 `topBar`；子页 `header` 标题居中化。
6. Emoji/Lucide 规则、颜色 token 规则照旧（见 `docs/首页美化方案.md` §四）。
