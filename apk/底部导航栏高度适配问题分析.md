# 底部导航栏高度适配问题分析

> 问题：底部三个按钮（首页 / 聊天 / 设置）在某些手机上被挤出屏幕看不到，在另一些手机上又太短。底部固定导航没有自动适应不同屏幕高度。

---

## 一、现象描述

| 问题 | 表现 |
|---|---|
| **你的手机** | 底部三个按钮看不到，被挤出屏幕下方 |
| **别人的手机** | 底部按钮太短 / 下方留白太多 |
| **期望** | 底部导航栏始终固定在屏幕底部，不管屏幕多高多矮，三个按钮始终可见 |

---

## 二、根因分析

### 2.1 当前布局结构

`Ui.screen()` 创建一个普通的 `LinearLayout(VERTICAL)`，所有内容**按顺序**从上到下排列：

```
LinearLayout (VERTICAL)    ← Ui.screen()
  ├── 标题
  ├── 空格
  ├── 副标题
  ├── 空格
  ├── 欢迎卡
  ├── 空格
  ├── 进度卡
  ├── 空格
  ├── 错误卡
  ├── 空格
  ├── 功能按钮网格
  ├── 空格
  ├── 包名版本号
  └── bottomBar()          ← 最后一个子 View，没有任何固定机制
```

关键代码在 [Ui.java](file:///Users/Banner/Documents/guomengtao/ev-schedule-android/apk/src/com/application/watch/classschedule/Ui.java#L35-L41)：

```java
public static LinearLayout screen(Activity a) {
    LinearLayout root = new LinearLayout(a);
    root.setOrientation(LinearLayout.VERTICAL);
    root.setBackgroundColor(BG);
    root.setPadding(dp(a, 14), dp(a, 14), dp(a, 14), dp(a, 14));
    return root;
}
```

各 Activity 的用法（以 HomeActivity 为例，[HomeActivity.java](file:///Users/Banner/Documents/guomengtao/ev-schedule-android/apk/src/com/application/watch/classschedule/HomeActivity.java#L68-L138)）：

```java
// buildUi() 中
LinearLayout root = Ui.screen(this);
root.addView(...标题...);
root.addView(...欢迎卡...);
root.addView(...进度卡...);
root.addView(...错误卡...);
root.addView(...功能按钮...);
root.addView(Ui.bottomBar(this, 0));   // ← 最后加进去，没有 weight，没有固定
setContentView(root);
```

### 2.2 为什么会"看不到"？

`LinearLayout` 没有滚动能力。所有子 View 的高度加起来如果超过屏幕高度，**超出部分会被直接裁剪**。底部导航栏是最后一个子 View，首当其冲被"挤"出屏幕。

```
           ┌──────────────┐
           │   标题        │
           │   欢迎卡      │
  屏幕可见  │   进度卡      │
    区域   │   错误卡      │
           │   功能按钮    │
           │   版本号      │
           ├──────────────┤ ← 屏幕底部边界
  被裁剪   │ [首页][聊天]  │ ← 这三个按钮在屏幕外，看不到！
  区域     │ [设置]        │
           └──────────────┘
```

**影响因素**：
- 屏幕高度越矮，内容就越容易溢出（你的手机屏幕可能较矮）
- 系统状态栏 / 导航栏占用空间不同
- 错误卡（errorCard）显示时会额外增加高度，让问题更严重

### 2.3 为什么会"太短"？

在别人的手机上（屏幕较高），所有内容的总高度小于屏幕高度。底部导航栏就"悬"在内容下方，离屏幕底部有很大一段空白区域。没有利用 `layout_weight` 把中间内容区域撑开到填满剩余空间。

```
           ┌──────────────┐
           │   标题        │
           │   欢迎卡      │
           │   进度卡      │
           │   错误卡      │
           │   功能按钮    │
           │   版本号      │
           │ [首页][聊天]  │  ← 导航栏在这里
           │ [设置]        │
           │              │  ← 一大片空白
           │              │
           │              │
           └──────────────┘ ← 屏幕底部
```

## 四、修复方案

### 方案 A：FrameLayout + ScrollView（推荐）

将 `Ui.screen()` 重构为 `FrameLayout` 结构：

```
FrameLayout (MATCH_PARENT × MATCH_PARENT)
  ├── ScrollView (MATCH_PARENT × MATCH_PARENT, 内容可滚动)
  │     └── LinearLayout(VERTICAL)  ← 原来的内容
  │           ├── 标题
  │           ├── 欢迎卡
  │           ├── ...
  │           └── 版本号
  └── LinearLayout (bottomBar, layout_gravity=bottom)  ← 始终在底部
        ├── [首页]
        ├── [聊天]
        └── [设置]
```

**优点**：
- 底部栏真正"固定"在屏幕底部，不受内容高度影响
- 内容可滚动，超长时也不会丢失
- 高屏幕手机：底部栏贴在底部，不会悬空
- 矮屏幕手机：底部栏始终可见，内容可滚动查看

**需要改动的地方**：
1. [Ui.java](file:///Users/Banner/Documents/guomengtao/ev-schedule-android/apk/src/com/application/watch/classschedule/Ui.java) - 提供新的 `screenWithBottomBar()` 方法或重构 `screen()` 方法
2. 三个 Activity 的布局代码调整

### 方案 B：LinearLayout + weight（改动最小）

给底部栏设置 `layout_weight=0`（固定高度），给内容区域设置 `layout_weight=1`（撑满剩余空间），并把内容区包在 `ScrollView` 里：

```
LinearLayout(VERTICAL, MATCH_PARENT × MATCH_PARENT)
  ├── ScrollView (weight=1, 撑满剩余空间)
  │     └── LinearLayout(VERTICAL)  ← 内容
  └── LinearLayout (bottomBar, weight=0, 固定高度)
```

**优点**：改动量最小，只需要在 `Ui.java` 中加一个工具方法。

**缺点**：每个 Activity 的布局都需要改动，不够统一。

### 方案 C：提供新的 `screenWithBottomBar()` 方法（最佳实践）

在 [Ui.java](file:///Users/Banner/Documents/guomengtao/ev-schedule-android/apk/src/com/application/watch/classschedule/Ui.java) 中新增一个方法，接收 content View 和 bottomBar 参数，返回组装好的根布局。这样所有 Activity 只需一行代码即可获得正确布局。

## 五、额外注意：ChatActivity 的 ScrollView

[ChatActivity.java](file:///Users/Banner/Documents/guomengtao/ev-schedule-android/apk/src/com/application/watch/classschedule/ChatActivity.java#L72-L75) 中的消息列表已经有一个 `ScrollView`，且设置了 `weight=1`：

```java
scroll.addView(msgView);
root.addView(scroll, new LinearLayout.LayoutParams(
        LinearLayout.LayoutParams.MATCH_PARENT, 0, 1f));
```

这意味着 ChatActivity 的布局中**已经有一个按 weight 分配的 ScrollView**，但外层 root 仍然是普通 LinearLayout，没有整体滚动能力。如果其他内容（标题、状态行、输入框等）已经超出一屏，底部栏仍然会溢出。

**修复时需要注意不要嵌套两个纵向 ScrollView。**

---

## 六、总结

| 问题 | 根因 |
|---|---|
| 你的手机看不到底部按钮 | 内容总高度 > 屏幕高度，底部栏被裁剪 |
| 别人手机底部太短 | 内容总高度 < 屏幕高度，底部栏悬空没有贴底 |
| 三个按钮不会自动适应 | `LinearLayout` 没有使用 `weight` 或 `FrameLayout` 固定底部 |

**核心修复方向**：让底部导航栏使用 `FrameLayout`（`layout_gravity=bottom`）固定在屏幕底部，同时把上方内容放入 `ScrollView` 中可滚动。
